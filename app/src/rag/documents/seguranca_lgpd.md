# Segurança e Privacidade — Banco Ágil

## Autenticação no atendimento

O atendimento virtual exige CPF e data de nascimento antes de qualquer consulta ou
operação. São permitidas até três tentativas de autenticação por atendimento; esgotadas
as tentativas, o atendimento é encerrado e o cliente deve procurar os canais oficiais.

Contas com status diferente de "ativa" não são atendidas pelo canal virtual.

## Dados que o atendimento nunca solicita

O atendimento virtual **nunca** pede senha, PIN, código de verificação recebido por SMS,
número completo do cartão ou código de segurança (CVV). Qualquer contato que solicite
esses dados em nome do Banco Ágil deve ser tratado como tentativa de fraude.

## Tratamento de dados pessoais (LGPD)

Os dados fornecidos no atendimento são usados exclusivamente para autenticação, análise
de crédito e execução do serviço solicitado, conforme a Lei Geral de Proteção de Dados
(Lei nº 13.709/2018).

O cliente pode solicitar, a qualquer momento, confirmação do tratamento, acesso,
correção, portabilidade ou eliminação dos seus dados pessoais, além de revogar o
consentimento.

As informações da entrevista de crédito são usadas apenas para o cálculo do score e
ficam registradas para fins de auditoria da decisão.

## Registro de atendimento

Todo atendimento é registrado para fins de auditoria e melhoria do serviço. Erros
técnicos são registrados sem exposição de dados sensíveis do cliente.
