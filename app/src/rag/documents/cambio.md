# Câmbio — Banco Ágil

## Consulta de cotação

O atendimento consulta a cotação em tempo real das seguintes moedas, sempre convertidas
para o real brasileiro (BRL):

| Moeda | Código ISO 4217 |
| --- | --- |
| Dólar americano | USD |
| Euro | EUR |
| Libra esterlina | GBP |
| Peso argentino | ARS |
| Iene japonês | JPY |
| Franco suíço | CHF |
| Dólar canadense | CAD |
| Dólar australiano | AUD |
| Yuan chinês | CNY |
| Bitcoin | BTC |

Quando o cliente não especifica a moeda, a cotação apresentada é a do dólar americano.

## Natureza da cotação

O valor informado é o preço de compra (bid) de referência do mercado, atualizado ao
longo do dia útil. Não é uma proposta de operação: a taxa efetiva de uma compra ou venda
de moeda considera spread, IOF e tarifas do produto contratado.

Fora do horário de negociação, a cotação exibida é a do último fechamento.

## Limitações

O Banco Ágil não realiza remessas internacionais nem compra e venda de moeda em espécie
por meio do atendimento virtual. Moedas fora da lista acima não estão disponíveis para
consulta.
